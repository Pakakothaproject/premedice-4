# Premedice 4 — Roadmap

**Status:** Preview
**Last updated:** 3 November 2026

This roadmap describes direction, not delivery promises. Dates are intentionally omitted.

---

## Now

- [x] OpenAI-compatible chat endpoint
- [x] Model list endpoint
- [x] Lab interpretation endpoint
- [x] Evidence verification endpoint
- [x] MCP endpoint
- [x] API keys and usage accounting
- [x] Cited responses
- [x] Whole-record context in the app

## Next

- [ ] Public clinical evaluation results
- [ ] Published citation precision and red-flag recall
- [ ] Provider identity verification for doctors
- [ ] Signed, immutable doctor review
- [ ] Lab format coverage and backfill
- [ ] Health brief email delivery and unsubscribe
- [ ] Public latency and reliability reporting
- [ ] Model ID consistency across docs and API

## Later

- [ ] Country-specific lab ranges
- [ ] Spanish, Portuguese, Arabic, French, and German support
- [ ] FHIR export
- [ ] Trial eligibility matching
- [ ] CPIC/PharmGKB rule engine
- [ ] Prospective outcome study

## Not planned

- a foundation model trained from scratch
- autonomous diagnosis
- autonomous prescribing
- emergency triage
- a full EHR
- wearables in the first clinical release
